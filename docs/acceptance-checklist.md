# 手動驗收清單

請在不含真實使用者資料的測試 Sheet 完成以下驗收，並將結果記錄在不提交至 Git 的地方。

## 響應式與無障礙

- [ ] 375px 寬度：預設時間軸、頂部列、固定底部導覽與浮動新增按鈕可用。
- [ ] 768px 寬度：預設月曆、側欄與表單對話框可用。
- [ ] 1024px 以上：時間軸節點、月曆格與懸停操作按鈕排版正確。
- [ ] 可用鍵盤 Tab 移動到所有按鈕、表單欄位、月曆日期與對話框操作。

## 登入與初始化

- [ ] Vercel Production 已設定 `GOOGLE_CLIENT_ID`、`GOOGLE_CLIENT_SECRET`、`SESSION_ENCRYPTION_KEY`、`GAS_DEPLOYMENT_ID`，且沒有 `APP_GOOGLE_CLIENT_ID` 或 `APP_GAS_DEPLOYMENT_ID`。
- [ ] OAuth Web Client 的授權重新導向 URI 包含正式網址 `/api/auth/callback`。
- [ ] 清除網站 Cookie 後首次登入可完成 Google 授權並回到首頁。
- [ ] 刷新 Production 網站後可直接載入記事，沒有 Google 帳號選擇或同意畫面。
- [ ] 點選登出後刷新網站仍顯示登入畫面，且 Google Sheets 資料未被刪除。
- [ ] 撤銷 Google 授權後刷新網站顯示登入畫面；重新授權後 CRUD 與 CSV 匯出正常。
- [ ] 空白 Sheet 執行 `initializeJournal()` 後建立三張工作表及正確欄位。

## 記事與分類

- [ ] 新增含日期、分類、標題、內容、兩個標籤與兩筆連結的記事。
- [ ] 編輯記事、確認標籤去重與網址驗證。
- [ ] 無標題記事在時間軸顯示內容摘要。
- [ ] 刪除前出現確認對話框，確認後永久移除。
- [ ] 同一天建立多筆記事，順序由建立時間新到舊。
- [ ] 新增、重新命名、停用與重新啟用分類；停用後歷史記事仍保留該分類。
- [ ] 有記事的類別顯示完整記事數、可停用但不可永久刪除。
- [ ] 從類別管理搬移單筆記事至另一個啟用類別；確認時間軸、月曆與兩個類別的計數更新。
- [ ] 載入更多來源記事後跨頁勾選多筆、確認搬移；每筆只搬移一次且勾選在失敗後仍保留。
- [ ] 將來源類別記事全數搬走後永久刪除空類別；Google Sheets 只移除該類別列，不刪除記事。
- [ ] 停用類別不會出現在搬移目的地；確認前停用目的地或改變來源資料時，系統拒絕整批搬移。

## 查詢、月曆與匯出

- [ ] 關鍵字、日期區間、分類與標籤的四種條件交集正確。
- [ ] 時間軸「載入更多」可正確分頁。
- [ ] 月曆每日數量正確，點選有記事日期可開啟該日清單。
- [ ] 變更月曆月份後只取得該月份的每日計數。
- [ ] 匯出目前篩選結果與全部記事，使用 Excel 開啟時繁體中文與引號正確。

## 正式部署

- [ ] Vercel 正式網域以 HTTPS 提供網站、`/api/session` 與 `/api/journal`。
- [ ] 未將 Sheet ID、GAS Script ID、OAuth Client ID、帳號資料或存取權杖提交至 Git。
