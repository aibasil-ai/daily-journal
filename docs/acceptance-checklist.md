# 手動驗收清單

請在不含真實使用者資料的測試 Sheet 完成以下驗收，並將結果記錄在不提交至 Git 的地方。

## 響應式與無障礙

- [ ] 375px 寬度：預設時間軸、頂部列、固定底部導覽與浮動新增按鈕可用。
- [ ] 768px 寬度：預設月曆、側欄與表單對話框可用。
- [ ] 1024px 以上：時間軸節點、月曆格與懸停操作按鈕排版正確。
- [ ] 可用鍵盤 Tab 移動到所有按鈕、表單欄位、月曆日期與對話框操作。

## 登入與初始化

- [ ] 未設定部署變數時顯示明確設定錯誤。
- [ ] 首次登入可完成 Google OAuth 並載入啟用中的分類。
- [ ] 取消登入後顯示可重試訊息。
- [ ] 權杖過期或 GAS 權限不足時可重新登入。
- [ ] 空白 Sheet 執行 `initializeJournal()` 後建立三張工作表及正確欄位。

## 記事與分類

- [ ] 新增含日期、分類、標題、內容、兩個標籤與兩筆連結的記事。
- [ ] 編輯記事、確認標籤去重與網址驗證。
- [ ] 無標題記事在時間軸顯示內容摘要。
- [ ] 刪除前出現確認對話框，確認後永久移除。
- [ ] 同一天建立多筆記事，順序由建立時間新到舊。
- [ ] 新增、重新命名、停用與重新啟用分類；停用後歷史記事仍保留該分類。

## 查詢、月曆與匯出

- [ ] 關鍵字、日期區間、分類與標籤的四種條件交集正確。
- [ ] 時間軸「載入更多」可正確分頁。
- [ ] 月曆每日數量正確，點選有記事日期可開啟該日清單。
- [ ] 變更月曆月份後只取得該月份的每日計數。
- [ ] 匯出目前篩選結果與全部記事，使用 Excel 開啟時繁體中文與引號正確。

## 正式部署

- [ ] Vercel 正式網域已加入 OAuth 授權 JavaScript 來源，正式登入與 CRUD 可用。
- [ ] Cloudflare Pages、Netlify、GitHub Pages 或一般靜態主機至少擇一完成相同驗證。
- [ ] 未將 Sheet ID、GAS Script ID、OAuth Client ID、帳號資料或存取權杖提交至 Git。
