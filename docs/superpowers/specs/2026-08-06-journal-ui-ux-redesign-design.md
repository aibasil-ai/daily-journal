# 每日記事 UI/UX 重設計規格

## 目標

將 `docs/sample_pages` 的六個畫面轉為可運作的 React 介面：時間軸、月曆、月曆記事閱讀、分類管理、新增記事與編輯記事。視覺採用一致的淺色藍灰設計系統，桌面使用側欄，手機使用底部導覽與浮動新增按鈕。

既有 Google Sheets 資料模型、Vercel API、OAuth session、記事欄位與操作必須維持不變。

## 範圍

### 納入

- 將目前同頁堆疊的表單、分類、篩選、月曆與時間軸拆成三個主要工作區：時間軸、月曆、分類管理。
- 建立共用應用殼層，提供桌面側欄、手機底部導覽、目前視圖狀態、登出與 CSV 匯出入口。
- 建立聚焦式新增與編輯記事 Dialog：桌面置中卡片，手機全螢幕。
- 建立獨立記事閱讀視圖，可從時間軸或月曆中的日期選擇流程開啟，並提供編輯與刪除操作。
- 重做時間軸、月曆、分類管理、表單、錯誤與 loading 狀態的視覺與響應式樣式。
- 加入相應元件與流程測試，確保既有資料操作保持可用。

### 不納入

- 富文字編輯器、Markdown 預覽、圖片上傳或格式化工具列。
- 設定與支援頁面的實際功能。
- 新增資料庫欄位、改動 API 介面或引入 client-side router、Tailwind 或 UI 元件套件。

## 資訊架構與資料流

`JournalApplication` 維護目前主視圖、開啟中的編輯器、閱讀中的記事與月曆日期選擇狀態。`useJournal` 繼續是唯一的資料讀寫入口。

- `timeline` 主視圖顯示搜尋、進階篩選、依日期分組的記事卡與載入更多操作。
- `calendar` 主視圖顯示月份控制、符合既有篩選條件的每日數量，以及月曆日期選擇流程。
- `categories` 主視圖顯示獨立的分類卡片網格與現有新增、改名、停用功能。
- 側欄與手機底部導覽只切換主視圖，不重新讀取 session。
- 新增與編輯共用 `EntryForm`。成功儲存後關閉 Dialog，並讓既有 `saveEntry` 刷新目前列表與月曆數量。
- 時間軸卡片的主要點選區開啟閱讀視圖；閱讀視圖中的編輯會切換至同一筆記事的編輯 Dialog。
- 月曆日期選擇仍呼叫既有 `getEntriesForDate`。此 hook 會回傳該日已載入的記事，讓介面在一筆時直接開啟閱讀視圖，多筆時顯示小型記事選擇 Dialog。此設計不會因同日多筆記事而任意開啟第一筆。
- CSV 匯出仍使用既有 `exportEntries` 與 `downloadCsv`，從側欄匯出入口開啟範圍選擇；手機以主視圖操作提供相同功能。

## 元件調整

- `App.tsx`：建立應用殼層及視圖、編輯器、閱讀器與日期選擇的暫態 UI state。
- 新增導覽殼層元件，集中處理桌面側欄與手機底部導覽的目前狀態、鍵盤操作與登出。
- `EntryForm`：保留日期、分類、標題、純文字內容、標籤與參考連結欄位；改以聚焦式新增／編輯版面呈現，不提供範例稿中的富文字工具列。
- `Timeline` 與 `EntryCard`：新增開啟閱讀視圖的 callback，保留明確的編輯、刪除與刪除確認流程。
- `CalendarView`：採用月曆卡片格與每日記事數量 badge；月彙總 API 只提供數量，因此月格不顯示記事標題。點選日期後才載入當日資料並顯示標題選擇。保留週一為首日、月份切換與無障礙日期摘要。
- `CategoryManager`：保留資料操作與 native dialog 確認流程，改為獨立卡片網格與行內改名的呈現。

## 視覺系統

不直接使用範例 HTML 的 Tailwind CDN。`global.css` 建立可重用的 CSS variables 與元件 class：

- 背景與表面：`#f7f9fb`、`#f2f4f6`、`#ffffff`。
- 主色：`#004ac6`；主色容器：`#2563eb` 與淡色 `#dbe1ff`。
- 文字：`#191c1e` 與次要文字 `#434655`；邊框：`#c3c6d7`。
- 危險操作：`#ba1a1a`、`#ffdad6`。
- 圓角以 8px、12px 為主；卡片使用柔和 4px 至 12px 陰影；按鈕保留清楚的 hover、focus-visible、disabled 與 loading 狀態。
- 使用 Hanken Grotesk 與 Material Symbols。圖示按鈕必須提供 `aria-label`，文字按鈕不只依賴圖示傳達意義。

## 響應式與無障礙

- `768px` 以上使用 256px 固定側欄；內容區最大寬度 1200px。
- 小於 `768px` 隱藏側欄，顯示三個主視圖的底部導覽；新增記事改為浮動按鈕，內容保留底部安全間距。
- 閱讀與編輯等聚焦任務在手機隱藏全域導覽，保留明確返回或關閉按鈕。
- 所有 Dialog 使用 native `<dialog>` 或等效的 focus management，Esc、取消與關閉後焦點回復必須可用。
- 觸控目標最小高度維持 44px；日期、記事數、分類狀態與錯誤訊息不只以顏色區分。

## 錯誤處理

- API、儲存、刪除、分類與匯出錯誤仍使用既有繁體中文訊息與 `role="alert"`。
- 非同步操作期間停用重複提交；保留使用者已輸入的表單資料。
- 失效登入維持既有 session 清除與登入畫面，不讓暫態 Dialog 狀態留在已登出的畫面上。

- 覆蓋月曆一筆與多筆記事的選擇流程，並維持現有月份、週首日與無障礙日期摘要測試。

- 完成後執行 `npm run check`，並以 production build 檢查樣式與 TypeScript 編譯。
