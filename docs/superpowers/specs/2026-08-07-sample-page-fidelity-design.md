# 每日記事範例頁面逐頁對齊規格

## 目標

將現有 React 應用的六個功能畫面，逐頁對齊 `docs/sample_pages` 中指定的 HTML 範例：時間軸、月曆、月曆項目閱讀、新增記事、編輯記事與類別管理。

## 逐頁對應

| 功能 | 參考頁面 | 實作要求 |
| --- | --- | --- |
| 時間軸 | `時間軸頁面.html` | 使用範例的頁首搜尋／篩選控制列、日期時間線與記事卡片結構。 |
| 月曆 | `月曆頁面.html` | 使用月份標題、上一月／今天／下一月控制列與滿版七欄月格；只顯示現有 API 提供的每日數量。 |
| 月曆閱讀 | `月曆點選項目閱讀頁面.html` | 使用聚焦閱讀卡片、返回、編輯、刪除、分類、標籤與連結排版。 |
| 新增記事 | `新增記事頁面.html` | 使用任務聚焦的全頁表單與返回操作。 |
| 編輯記事 | `編輯記事頁面.html` | 使用置中大型 Dialog、標題列、刪除操作與頁尾儲存列。 |
| 類別管理 | `類別管理頁面.html` | 使用頁首新增按鈕與可掃讀的分類卡片網格。 |

## 實作邊界

- 不複製 Tailwind CDN、範例假資料、富文字工具列、設定或支援功能。
- 保留既有 Google Sheets 模型、Vercel API、OAuth session、記事欄位、CSV 匯出、分類確認與安全連結行為。
- 新增與編輯共用資料驗證，但以不同版面 class 實現指定範例的全頁新增與置中編輯。
- 同日多筆月曆項目仍先選擇記事，再進入閱讀頁；不能任意開啟第一筆。

## 視覺與響應式

- 保留 Hanken Grotesk、淺色藍灰 token、柔和陰影、12px 圓角與範例的標題層級、間距與操作位置。
- 桌面使用 256px 側欄；手機使用底部三主視圖導覽、浮動新增與更多操作。
- 新增與閱讀的手機聚焦頁隱藏全域導覽；任何長內容均可捲動且不被固定控制列遮擋。
- 所有可互動項目保持最小 44px、可見 focus、語意化標題與既有 Dialog 焦點管理。

## 驗證

- 更新時間軸、月曆、閱讀、新增、編輯與分類的元件／整合測試，確認各頁可及名稱與原有資料操作不變。
- 在 390px 與 1440px 檢查各頁沒有裁切、重疊或隱藏必要操作。
- 執行 `npm run check`，確保 lint、測試、NodeNext API 型別檢查、Vite build 與 GAS bundle 全部通過。
